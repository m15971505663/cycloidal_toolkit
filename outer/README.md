# 外摆线减速器 · 独立设计器（sign=−1）

自包含单文件 HTML（`cycloidal_outer_designer.html`），无外部依赖，双击打开或任意静态服务器均可跑。
与根目录 `src/` 的内摆演示同源不同支：**外摆 = 内摆整体内外翻转**（摆线轮在外包裹针齿）。

## 用法

```
# 方式一：直接双击 HTML
# 方式二：本地服务（推荐，改起来刷新方便）
python3 -m http.server 8766
# → http://localhost:8766/outer/cycloidal_outer_designer.html
```

## 功能

- **参数化**：zc / dp / Rp / K₁ / drp / din（动力输入距）/ capR（胶囊半径）/ 速度 / 缩放
- **默认啮合态**：三件（胶囊+摆线轮+偏心圆）锁死成完整刚体显示；点「啮合」切居中看齿廓，「摆线生成动画」自动切非啮合
- **运转**：刚体圆周平动（平行四边形），针齿被拨动慢转 = 输出，减速比 **1:zp**
- **三片叠加**：120° 偏心相位（动平衡）+ 齿廓错位 phase/(zp+1)（保证三片都啮合）

## 关键技术（改造前先看，全是踩过的坑）

### ① 外摆 sign=−1 的两处（漏一处就不对）

```
xa = R·cos t − SIGN·e·cos(zp·t)     // SIGN 只乘 x 的 e 项！
ya = R·sin t − e·sin(zp·t)           // y 项恒定不乘
等距偏移 o = SIGN·off/denom           // 偏移方向跟 sign：外摆外胀包裹针齿
```

- 两项一起翻号 = 只是把曲线转半齿，形状不变（错）
- 偏移不跟 sign = 齿廓不包裹针齿（错）

### ② 啮合运动学（trochoid 共轭推导）

- 刚体**圆周平动** th=0（不自转），摆线轮中心角 = 输入角 φ（偏心套与摆线轮锁死同角 = 平行四边形）
- **针齿是输出**：转 `−φ/zp`，减速比 **1:zp**（输入一圈拨一格）
- 验证式：`pin_i(φ) − C(φ) = (R·cos(α_i−φ/zp) + e·cosφ, R·sin(α_i−φ/zp) + e·sinφ) = trochoid(α_i−φ/zp)` ✓

### ③ 三片叠加（120°）

- 偏心相位差 120°：`memberPose(P, phase)`，phase = 0 / 2π/3 / 4π/3（动平衡）
- **齿廓错位 = phase/(zp+1)**（凸瓣数 zp+1）：类比内摆双片齿错半齿距 π/zc，不错位三片重叠必干涉
- 要求 zp+1 是 3 的倍数（默认 zp=11 → 12 凸瓣，120° 正好错 4 瓣）

### ④ 结构分层

- `drawDisc(phase, col, ...)` 画**一片完整刚体**：胶囊(两端=摆线轮中心 O+C & 偏心套中心 din+C，同偏移平动) + 摆线轮齿廓 + 偏心圆(只轮廓)
- 输入轴心 din / 壳心 O 是公共固定点，不随片动
- 胶囊+摆线轮为面板刚体（evenodd 填充，齿廓内和偏心圆内挖空）；偏心套独立件（只轮廓）

## 与内摆（src/）差异速查

| | 内摆 | 外摆（本页） |
|---|---|---|
| sign | +1（epitrochoid） | −1（hypotrochoid） |
| 摆线轮位置 | 内部实心盘，针齿在外 | 外齿圈包裹针齿 |
| 输入/输出 | 偏心轴输入，摆线轮经 W 机构输出 | **摆线轮(刚体)平动输入，针齿直接输出** |
| W 机构 | 必需 | **无** |
| 多片 | 双片 180°，齿错 π/zc | 三片 120°，齿错 phase/(zp+1) |
| 减速比 | 1:(zp−1) | **1:zp** |
